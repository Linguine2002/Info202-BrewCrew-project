# ☕ Info202-BrewCrew-project - Web Service Application

Welcome to the official repository for our INFO 202 Group Project. We have developed a responsive, multi-page web application simulating a modern cafe experience integrated with live data.

## 🔗 Public API Integration
* **API Used:** TheMealDB API
* **Documentation Link:** https://themealdb.com
* **Project Use Case:** Users can interact with our Search Feature page to query the cafe database for pastry, dessert, and meal options by keyword or ingredient, returning live images, descriptions, and recipes dynamically.

## 📱 Application Features & Pages
1. **Home Page (`index.html`):** An elegant welcome portal introducing our cafe concept, operational hours, and service background.
2. **Menu Search (`search.html`):** A dynamic data interface that handles live text inputs and formats API ingredient results into responsive Bootstrap item cards.
3. **Contact Us (`contact.html`):** A client feedback portal built with strict JavaScript data validation to secure user message entries.
4. **Our Team (`members.html`):** A professional profile grid showcasing team identities, collaborative roles, and contributions.

## 💻 Local Setup Instructions
To launch and review this application locally:
1. Clone this repository or download the source ZIP file.
2. Navigate to the root directory and open `index.html` using any modern web browser (Chrome, Safari, Edge).
3. Ensure you have an active internet connection to process the live client-side API requests.
